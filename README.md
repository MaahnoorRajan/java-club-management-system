# Java Club Management System

A console-based Java coursework project by Maahnoor Rajan, imported from previous coursework. It models university clubs, members, leaders, and activities using object-oriented programming.

This initial import preserves the application logic, including known compilation errors. Sample names and email addresses were replaced with clearly fictional demo data for publication. IDE files, compiled output, and archives are excluded.

Follow-up commits will fix compilation, leader removal, club deletion, and documentation. No historical dates or contribution activity are fabricated.
